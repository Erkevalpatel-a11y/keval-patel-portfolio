# Keval Patel Portfolio

Premium animated static portfolio for Keval Patel.

## Included
- Animated welcome screen
- Responsive portfolio layout
- About, Experience, Skills, License and Badge, Certifications, Work, Featured Project, Journey and Contact sections
- Five interaction styles: Pulse Glow, Liquid Sliding Fill, 3D Cyber Bounce, Neon Border Draw and Elegant Magnet Expand
- SEO metadata, Open Graph metadata and Person structured data
- robots.txt and sitemap.xml for search-engine discovery
- Local profile image, badge artwork and work visuals
- GTU ML project link

## Local run
Open CMD in this folder and run:

```cmd
py -m http.server 5500
```

Then open `http://localhost:5500`.

## Vercel
This is a static site. Import the repository into Vercel with Framework Preset **Other**, Build Command empty and Output Directory `.`.

If Vercel gives the project a URL different from `https://keval-patel-portfolio.vercel.app/`, update the URL in `robots.txt`, `sitemap.xml` and the SEO/canonical fields in `index.html` before submitting the site to Google Search Console.
